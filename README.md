# Anneer Center website

Source for [anneer.org](https://anneer.org), published with GitHub Pages.

- `tools/build.py` builds every page. Run `python3 tools/build.py` from the repository root.
- `content/articles.json` holds the article text; article metadata and page copy live in `tools/build.py`.
- `assets/` holds the stylesheet, images and PDFs.
